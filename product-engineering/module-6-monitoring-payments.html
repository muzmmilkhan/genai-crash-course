Monitoring, Logging and Payments

See what your system is doing in production, and add payments so your product can earn money.

Logs, metrics and alerts

Once real users arrive, you cannot watch the code run. Monitoring tells you something is wrong, and logs tell you why.

SignalQuestion it answersExample
LogsWhat happened?Error stack trace, a request line
MetricsHow is it doing over time?Requests per second, p95 latency, error rate
AlertsDo I need to act now?Error rate above 2% for 5 minutes

The tools

ToolRole
PrometheusCollects and stores metrics
GrafanaDashboards and alerting on top of metrics and logs
ELK stackElasticsearch, Logstash and Kibana: collect, search and visualize logs
💡 Tip: Log in a structured format (JSON) with a request ID, so one user's journey can be traced across services.

What to watch in an AI product

  • Latency of model calls, and time to first token if you stream.
  • Token usage and cost per user and per feature.
  • Error and timeout rates from the model provider.
  • Quality signals: thumbs up or down, fallback rate, retrieval hit rate.
  • Cache hit rate, since it directly cuts cost.
⚠️ Careful: Do not log sensitive user data or full prompts without a clear reason and a retention limit.

Payment gateways

A payment gateway handles cards and other methods, compliance and fraud checks so you never store card numbers yourself.

GatewayTypical fit
StripeGlobal products, subscriptions, strong developer experience
RazorpayProducts selling in India, with UPI and local methods
  • Use hosted checkout where possible.
  • Rely on webhooks to confirm payment, not the browser redirect.
  • Verify webhook signatures and make handlers idempotent.
  • Model plans, usage limits and invoices in your database.
# webhook handler sketch
event = verify_signature(request.body, request.headers["signature"])
if event.type == "payment.succeeded":
    activate_plan(event.customer_id)   # safe to run twice

Pricing AI products

Model calls cost money on every use, so pricing must cover that cost.

  • Estimate cost per active user, then price with a healthy margin.
  • Offer a free tier with hard limits.
  • Meter usage (credits, tokens or actions) for heavy features.
